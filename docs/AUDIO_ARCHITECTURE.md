# Napflix Audio Architecture

## Core Goal

Napflix audio should feel:
- warm
- cinematic
- high-fidelity
- seamless
- appliance-like

Audio should never feel:
- glitchy
- delayed
- Linux-like
- device-confused

---

# Primary Audio Path

Preferred:
DAC HAT or USB DAC.

Fallback:
HDMI audio.

Avoid:
cheap onboard analog output.
