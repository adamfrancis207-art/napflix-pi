# Napflix Input Architecture

## Core Principle

Napflix is remote-first.

The experience should feel natural from a couch at 10 feet away.

Mouse and keyboard are secondary.

---

# Primary Inputs

## Remote Control

Primary navigation device.

Required Inputs:
- Up
- Down
- Left
- Right
- Select
- Back
- Home
- Play/Pause

Preferred:
- volume wheel
- dedicated media buttons
- tactile feedback

---

## Keyboard

Secondary maintenance device.

Used for:
- setup
- debugging
- admin tasks
- emergency recovery

Should rarely be needed during normal use.

---

## Mouse

Avoid dependency.

The UI should never require precise pointer interaction.

---

# Navigation Philosophy

The interface should:
- feel directional
- snap predictably
- animate smoothly
- maintain focus visibility
- never lose cursor position

Avoid:
- tiny clickable areas
- hidden focus states
- hover-dependent UI
- desktop-style interaction

---

# Focus System

Every screen must support:
- directional navigation
- visible selection state
- predictable movement
- fast recovery if focus lost

---

# Audio Navigation

Future possibility:
- subtle navigation sounds
- soft clicks
- ambient UI tones

Avoid:
- loud arcade sounds
- harsh menu beeps

---

# Long-Term Goal

Navigation should feel:
- tactile
- effortless
- cinematic
- calm

Like:
- premium cable hardware
- luxury AV equipment
- old-school media systems
