# Napflix Mode System

Napflix operates in dedicated modes.

Each mode should feel distinct but unified.

---

# 1. TV MODE

Purpose:
Channel surfing and passive watching.

Features:
- TV Guide
- PJTV
- FAST channels
- channel logos
- fullscreen preview
- cable-style navigation

Mood:
Late-night cable television.

---

# 2. CINEMA MODE

Purpose:
Intentional movie watching.

Features:
- cinematic artwork
- trailers
- actor info
- collection browsing
- dimmed UI
- immersive transitions

Mood:
Boutique home theater.

---

# 3. MUSIC MODE

Purpose:
Active and ambient listening.

Features:
- Spotify
- Plex music
- visualizers
- metadata display
- VU meters
- front display integration

Mood:
Luxury stereo system.

---

# 4. AMBIENT MODE

Purpose:
Idle atmosphere.

Features:
- drifting artwork
- visualizers
- screensavers
- weather visuals
- soft motion
- clock mode

Mood:
Dreamlike media object.

---

# 5. ARCADE MODE

Purpose:
Retro gaming.

Features:
- emulator launcher
- CRT shaders
- cartridge-style presentation
- retro sound effects

Mood:
90s basement nostalgia.

---

# 6. ADMIN MODE

Purpose:
Maintenance and setup.

Features:
- system controls
- updates
- debugging
- storage management
- network tools

Hidden from normal viewing.

---

# Long-Term Goal

Modes should feel like:
different personalities
inside the same machine.
