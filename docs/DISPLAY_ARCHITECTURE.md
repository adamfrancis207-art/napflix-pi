# Napflix Display Architecture

## Main Display (TV)

Purpose:
Primary viewing/navigation interface.

Modes:
- TV Guide
- Movies
- Shows
- PJTV
- Streaming apps
- Arcade mode
- Ambient mode

Characteristics:
- fullscreen
- remote-driven
- cinematic UI
- 10-foot interface
- dark environment optimized

---

## Secondary Display (Front Panel)

Purpose:
Ambient metadata display similar to boutique hi-fi streamers and DACs.

Possible Information:
- album artwork
- track title
- artist
- codec
- bitrate
- sample rate
- bit depth
- playback progress
- VU meters
- clock
- network info
- PJTV channel info
- weather
- ambient visualizers

Design Style:
- premium stereo equipment
- Winamp visualizers
- Plexamp
- retro-future AV hardware
- minimalist typography

Behavior:
- always-on
- reacts to playback
- independent of TV state
- low-distraction
- ambient glow aesthetic

Future:
- animated transitions
- fake CRT effects
- audio-reactive motion
- custom Napflix idle screens
