# Napflix UI Philosophy

Napflix should feel like:

- a forgotten premium cable box
- a boutique hi-fi streamer
- a retro-future media appliance
- late-night TV from an alternate timeline
- tactile and cinematic
- calm and ambient
- remote-first, not mouse-first

Avoid:
- gamer aesthetics
- RGB overload
- cluttered dashboards
- overly modern streaming UI
- tiny text
- desktop-app feeling

Core Inspirations:
- Winamp
- Kaleidescape
- Plexamp
- TiVo
- Windows Media Center
- early Netflix desktop
- late 90s cable guides
- boutique DAC displays
- VHS/DVD menu systems

Core Principles:
- large typography
- smooth transitions
- ambient movement
- cinematic artwork
- focused navigation
- minimal friction
- media-first experience

Modes:
- TV
- Music
- Cinema
- Ambient
- Arcade

The system should feel:
warm
nostalgic
premium
slightly mysterious
